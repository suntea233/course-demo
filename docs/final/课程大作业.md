# 课程项目

同学们可以挑选以下题目开展课程项目，也可以自己提出题目，但是需要经过老师的审核。
点击就可以跳转对应项目的详细说明。

## 组队规则
1-3人组队

## 时间点
- Proposal：
    - 提交内容：选题、组队情况、研究计划
    - 截止时间：5月8日
- Milestone:
    - 提交内容：进展报告（进度、初步成果、下一步计划）
    - 截止时间：5月28日
- Final:
    - 答辩日期：6月10日
    - 提交内容：
        - 论文、代码、答辩PPT
    - 论文写作要求：
        - 请使用 NeurIPS 模板
        - 正文长度控制在 8-9 页
        - 全文统一使用英文
        - 建议包含以下部分：Abstract、Introduction、Related Work、Method、Experiment、Conclusion
        - 其中：
            - Abstract：简要概括全文内容
            - Introduction：阐述任务、背景、动机、工作内容、贡献和创新点等
            - Related Work：介绍与任务和方法相关的背景或技术
            - Method：重点描述所做工作，可通过图示、公式、算法等方式展示细节与重点
            - Experiment：展示实验设置与结果，建议包括性能比较、部件消融、案例分析、可视化等
            - Conclusion：总结全文工作与结论
        - Reference 和 Appendix 不限制页数
    - 提交形式：
        - 论文请提交 PDF 文件
        - 代码请提交完整代码压缩包，格式为 ZIP
        - 答辩PPT请提交 PDF 或 PPTX 文件
        - 统一上传至 selearning 网站
    - 提交要求：
        - 每支队伍仅需由队长提交一次
        - 文件命名格式为：
            - `Final_paper_队长学号_队长姓名.pdf`
            - `Final_code_队长学号_队长姓名.zip`
            - `Final_答辩ppt_队长学号_队长姓名.pdf`
        - 示例：`Final_paper_123456789_张三.pdf`
    - 提交截止时间：7月8日 23:59:59
    - 迟交说明：本次提交不允许迟交，未提交者本次提交计 0 分
